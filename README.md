# 狱国争霸（复刻版）

抖音小游戏《狱国争霸》的复刻：**三国杀身份局 + 连线出兵攻城占地**。十殿阎王争夺狱国，主公身份公开，忠臣、反贼、内奸各怀鬼胎——你要一边扩张地盘，一边从别人的行为里猜出谁是敌、谁是友。

纯 Canvas 2D + 原生 JavaScript，无任何依赖。同一套代码可以直接在**浏览器**和**抖音小游戏**里运行。

## 怎么玩

### 身份（与三国杀身份局一致）

| 身份 | 胜利条件 |
| --- | --- |
| 主公 | 消灭所有反贼和内奸（身份公开，主城上有王冠） |
| 忠臣 | 保护主公，消灭所有反贼和内奸 |
| 反贼 | 攻破主公的主城 |
| 内奸 | 先除掉其他所有人，最后单挑主公 |

- 人数配置：5 人（1 主 1 忠 2 反 1 内）、6 人（1 主 1 忠 3 反 1 内）、8 人（1 主 2 忠 4 反 1 内）。
- 除主公外身份隐藏，**阵亡时亮明身份**。阵亡不等于失败，胜负按阵营结算（可以继续观战）。
- 主公阵亡时，如果场上只剩内奸，则内奸胜；否则反贼胜。

### 名声：跳忠 / 跳反

没人知道你的身份，但大家都看得到你在打谁：

- 攻打主公 → 被标为 **「疑反」**
- 攻打「疑反」者 → 被标为 **「疑忠」**
- 向主公**进贡**（送兵入主公的城池）→ **「疑忠」**。忠臣可以用它救主，内奸和反贼也可以用它伪装。

电脑玩家完全依据这些公开信息行动：忠臣会围攻疑反者，主公会放过疑忠者（所以主公误杀忠臣也是可能的）。它们同样只能沿道路连线：会推演一场围攻能否打下再决定连线、打不下来就断线、从后方拉补给线支援前线；被主公领地挡住的忠臣会把兵力进贡给主公。

### 连线出兵

- **道路**：城池之间有固定的道路网，**只能攻打有道路相连的相邻城池**。想打远处的城，要一路打过去。
- **连线**：从己方城池拖到相邻城池建立连线（也可以先点己方城池、再点目标）。连线后部队沿道路**源源不断地出兵**，直到断线。拖动时划过的己方城池会一起连线。
- **流量**：每条连线每秒出兵 = 等级基础（2.5 / 3.5 / 4.5）+ 城内兵力 × 0.04，城里兵越多推得越猛；兵出光了就按产兵速度继续出。
- **输送**：连到自己的城池就是输送兵力，可以把后方的兵沿道路送到前线。攻下目标后连线自动变成输送线。
- **断线**：在连线上划一下；或者再拖一次同一条线；或者点城池里的「断开连线」、底部的「全部断线」。目标城池被别人抢走时，攻打它的连线会自动断开。
- **连线上限**：每座城同时能连的线数等于它的等级（主城 +1），超出时替换最早的一条。

### 操作

- **升级**：点击己方城池，消耗兵力升级（最高 3 级），提升兵力上限、产兵速度、出兵流量和连线数。
- **进贡**：点击相邻的主公城池，从与它相连的己方城池送一半兵力。
- **锦囊**：点击卡牌使用，需要目标的再点一座城池。
- 右下角：全部断线、暂停、倍速。

### 城池

| 城池 | 效果 |
| --- | --- |
| 都 · 主城 | 产兵快、城防 ×2；**被攻破即阵亡**；开局免战 60 秒；连线出兵时至少留守三成兵力 |
| 城 · 城池 | 普通城池 |
| 戟 · 兵营 | 训练重戟兵，攻击力 ×1.5 |
| 骑 · 马场 | 训练骑兵，行军速度 ×1.7 |
| 塔 · 箭塔 | 自动射杀射程内的敌兵，城防 ×1.5 |

地图中央的「酆都」是 2 级中立大城。行军中的不同势力部队相遇会互相厮杀（双向连线的部队会在道路上对冲）。

### 锦囊

每 20 秒摸一张（上限 3 张）：

| 锦囊 | 效果 |
| --- | --- |
| 无中生有 | 己方一座城池 +25 兵 |
| 万箭齐发 | 任意一座他方城池兵力 -45% |
| 南蛮入侵 | 其他所有势力的城池兵力 -20% |
| 桃 | 己方所有城池 +8 兵 |
| 无懈可击 | 己方一座城池 8 秒内免疫攻击 |

### 奖惩

- 击杀反贼：摸 2 张锦囊（可以超出上限到 4 张）。
- 主公误杀忠臣：弃置全部锦囊，全军兵力减半。
- 阵亡者的主城归攻破者，其余城池沦为中立。
- 6 分钟后「阴兵暴动」连线出兵加速，9 分钟、12 分钟后城防逐步崩坏，保证对局能结束。

## 运行

### 浏览器

直接用浏览器打开 `index.html` 即可（不需要服务器）。手机上竖屏体验最好，电脑上会以竖屏比例居中显示。

也可以启动一个本地静态服务器：

```bash
npm start   # http://localhost:8080
```

打包成单个 HTML 文件（方便分享）：

```bash
npm run build:web   # 输出 dist/yuguo-zhengba.html
```

### 抖音小游戏

1. 打开 [抖音开发者工具](https://developer.open-douyin.com/)，选择「导入项目」，目录选本仓库根目录。
2. 把 `project.config.json` 里的 `appid` 换成你自己的小游戏 AppID（或在工具里选择测试号）。
3. 入口是 `game.js`，竖屏、无状态栏（见 `game.json`）。`tests/`、`tools/`、`index.html` 等文件已在 `packOptions.ignore` 中排除，不会打进包里。

## 项目结构

```
index.html            浏览器入口
game.js / game.json   抖音小游戏入口与配置
project.config.json   抖音开发者工具项目配置
js/
  config.js           数值表：身份、城池、锦囊、节奏、难度
  util.js             可复现随机数、几何、颜色工具
  mapgen.js           地图生成（主城环形分布 + 泊松采样散布城池 + 不交叉的道路网）
  world.js            核心模拟：道路连线、行军、交战、攻城、名声、锦囊、阵亡与胜负判定
  ai.js               电脑玩家（按身份决策，只使用公开信息）
  render.js           绘图工具与战场渲染
  scenes.js           主菜单 / 玩法说明 / 对局 HUD 与交互 / 结算
  platform.js         平台适配：浏览器 与 抖音 tt.* API
  main.js             分辨率适配、主循环、场景切换、存档
tests/                规则单元测试 + 全 AI 对局测试
tools/
  simulate.js         批量 AI 对局，统计各阵营胜率
  build-web.js        打包单文件 HTML
```

核心模拟（`world.js` + `ai.js`）不依赖任何渲染或平台 API，使用固定步长和可复现随机数，所以可以在 Node 里直接跑完整对局。

## 测试与平衡

```bash
npm test              # 规则测试 + 5/6/8 人局 × 三档难度的 AI 对局
npm run sim -- 60     # 每种人数各模拟 60 局，输出胜率和平均时长
```

当前全 AI 对局（普通难度）大致结果：各阵营都有稳定的胜场，平均 5～7 分钟一局，没有超时局。随机种子不同，胜率会有较大波动。

## 关于复刻

原作的公开资料很少，能确认的核心是：抖音小游戏、三国杀式身份（主公 / 忠臣 / 反贼 / 内奸）、连线派小兵攻城占地，以及玩家攻略里提到的「开局向主城示好、中期扩张领土、后期保护主城」「内奸必要时要保护主公」「重戟兵」等要素。本项目据此还原了这些玩法；具体数值、城池种类、锦囊、地府题材的美术和 AI 策略是自行设计的，并非原作数据。
